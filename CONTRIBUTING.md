# Contributing to ExpenseTracker AI

Thank you for your interest in contributing to ExpenseTracker AI! This project is maintained and co-created by **Sai081** and **ChKarthik0**.

## Code of Conduct
Please review and adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all project interactions.

## How Can I Contribute?

### Reporting Bugs
Before creating bug reports, please check existing issues. When creating a bug report via the issue template, please include:
* A clear title and detailed description
* Steps to reproduce
* Device, browser, and platform information
* Screenshots or console logs if available

### Suggesting Enhancements
Feature requests and UI suggestions are welcome! Submit an issue with:
* A clear description of the desired feature
* Why this feature would be useful
* Any mockup screenshots or UI examples

### Pull Requests
1. Fork the repo and create your branch from `main`:
   ```bash
   git checkout -b feature/amazing-feature
   ```
2. Ensure frontend code passes build tests:
   ```bash
   cd frontend
   npm run build
   ```
3. Ensure backend Python code passes syntax check:
   ```bash
   python -m py_compile run.py app/*.py
   ```
4. Commit your changes following conventional commits:
   ```bash
   git commit -m 'feat: add amazing feature'
   ```
5. Push to your branch and open a Pull Request.
