# Security Policy

## Supported Versions
ExpenseTracker AI actively maintains the current production release.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of personal finance telemetry and user data seriously. If you discover a security vulnerability in ExpenseTracker AI, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Reach out directly to the maintainers:
   * **Sai081** ([@Sai081](https://github.com/Sai081))
   * **ChKarthik0** ([@ChKarthik0](https://github.com/ChKarthik0))
3. Include details regarding:
   * Type of vulnerability
   * Steps to reproduce
   * Potential impact on user financial records or API keys

We will review reports within 48 hours and work with you on a coordinated fix and release.
